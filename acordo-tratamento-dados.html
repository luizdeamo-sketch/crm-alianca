Acordo de Tratamento de Dados Pessoais (LGPD)

CRM Aliança by Capacity Case · Versão 2026-10-30 · parte integrante dos Termos de Uso

Este Acordo regula o tratamento de dados pessoais feito pela Capacity Case (CNPJ [CNPJ da Capacity Case]) para o Cliente que usa o CRM Aliança, nos termos da Lei nº 13.709/2018 (LGPD).

1. Papéis

  • O Cliente é o controlador: decide quais dados coloca no Sistema e para quê.
  • A Capacity Case é a operadora: trata os dados apenas para prestar o serviço e conforme as instruções do Cliente, que são o próprio uso do Sistema.

2. Dados tratados

Dados de clientes e contatos do Cliente (nome, CPF, contato, endereço, profissão, família), apólices, cotações, documentos, reuniões e o histórico de atendimento, além dos dados dos usuários da equipe do Cliente (nome, e-mail e registros de uso do Sistema).

3. Finalidade

Exclusivamente operar o Sistema: guardar, organizar, exibir e processar as informações para a gestão comercial do Cliente, inclusive gerar avisos, relatórios e, quando o Cliente usar, as leituras com inteligência artificial.

4. Confidencialidade e isolamento

  • Cada Cliente vê somente os próprios dados. O isolamento é feito no banco de dados, em cada tabela e em cada arquivo.
  • A equipe da Capacity Case só acessa dados do Cliente quando ele pedir suporte ou quando for necessário para manter o serviço funcionando, com sigilo.

5. Segurança

  • Conexões sempre criptografadas (HTTPS), banco de dados com controle de acesso por linha e por corretora, confirmação em 2 etapas disponível e registro de auditoria das alterações.
  • Cópias de segurança diárias.

6. Suboperadores

O Cliente autoriza o uso dos seguintes fornecedores, que seguem padrões de segurança compatíveis com a LGPD:

  • Supabase (banco de dados, arquivos e autenticação), com servidores na região de São Paulo (Brasil);
  • GitHub Pages (publicação das telas do Sistema; não guarda dados de clientes);
  • Anthropic (inteligência artificial), apenas quando o Cliente usa as leituras com IA: o conteúdo é enviado no momento da leitura e não é usado para treinar modelos.

Mudanças relevantes de suboperador serão avisadas com antecedência.

7. Direitos dos titulares

Pedidos dos titulares (acesso, correção, exclusão) são atendidos pelo Cliente. O Sistema permite consultar, corrigir e excluir os registros, e a Capacity Case ajuda o Cliente quando necessário.

8. Incidentes

Se houver incidente de segurança que possa afetar os dados do Cliente, a Capacity Case avisa o Cliente em até 48 (quarenta e oito) horas da descoberta, com o que se sabe e as medidas tomadas, para que o Cliente cumpra as suas obrigações perante a ANPD e os titulares.

9. Término

Ao fim do contrato, a Capacity Case entrega ao Cliente, se pedido em até 30 (trinta) dias, a exportação dos dados, e depois os exclui, inclusive das cópias de segurança no ciclo normal de renovação delas, salvo obrigação legal de guarda.
